# README

## 简介 Introduction

> [Git-Started][repo-url] 项目是一个快速搭建 Git 仓库的脚手架。这里面包含了一组基于 Node、Git-Cliff、NerdBank.GitVersion 的工作流工具。
>
> The [Git-Started][repo-url] project is a scaffold for quickly setting up Git repositories. It includes a set of workflow tools based on Node, Git-Cliff, and NerdBank.GitVersion.

## 如何使用 How to use it?

```powershell
## Use tiged
npx tiged github:source-club/get-started#dev ./get-started-copy

## Or degit
npx degit github:source-club/get-started#dev ./get-started-copy
```
